================================================================================
                              API ENDPOINTS
================================================================================

GET /api/admin/stats
  Returns: Statistics dashboard data
  Uses: Token + Admin role

GET /api/admin/vendors?page=1&limit=10&status=active&tier=pro&search=john
  Parameters: page, limit, status, tier, search
  Returns: Vendors array + pagination

GET /api/admin/vendors/{vendorId}
  Returns: Vendor details + recent transactions

PUT /api/admin/vendors/{vendorId}
  Body: Update vendor fields
  Returns: Updated vendor data

POST /api/admin/vendors/{vendorId}/activate
  Returns: Activation confirmation

POST /api/admin/vendors/{vendorId}/deactivate
  Body: Reason for deactivation
  Returns: Deactivation confirmation

DELETE /api/admin/vendors/{vendorId}
  Body: Reason for deletion
  Returns: Deletion confirmation

GET /api/admin/vendors/{vendorId}/transactions
  Returns: Vendor transaction history with pagination

================================================================================
                           TROUBLESHOOTING
================================================================================

Issue: "Admin access required"
Fix: Make sure you're logged in as admin@wishlist.com

Issue: Vendors not loading
Fix: Check server is running (npm run dev) and MongoDB is connected

Issue: Can't activate vendor
Fix: Vendor must have an active subscription first

Issue: Delete button not responding
Fix: Make sure you confirm the popup dialogs (requires explicit confirmation)

Issue: Statistics not updating
Fix: Refresh page with F5 or wait a few seconds (auto-updates)

Issue: Search not working
Fix: Type vendor name or email and press Enter or click Apply button
