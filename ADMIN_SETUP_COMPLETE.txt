Project setup notes

The application uses Express, Sequelize, and SQLite. The server stores its database in server/wishlist.db and serves the static pages from public/.

Configuration
- Copy server/.env.example to server/.env.
- Set JWT_SECRET and CORS_ORIGIN before starting the server.
- Set Paystack keys to enable vendor subscription checkout.
- Set ADMIN_EMAIL, ADMIN_PASSWORD, and ADMIN_NAME to create the administrator account.

Commands from the repository root
- npm install
- npm run create-admin
- npm start
- npm test
- npm run seed:deals (optional development examples)

Deal creation is vendor-only and requires an active, unexpired subscription. Admin functions are limited to vendor management; vendors manage their own deals from the vendor dashboard.
